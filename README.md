# snip-to-chat

Windows에서 단축키로 창이나 영역을 골라 **Claude 데스크톱 입력칸에 바로 첨부**하는 도구예요.
Mac판 Claude의 빠른 캡처(Option 두 번)를 Windows에서 비슷하게 쓰려고 만들었어요.

> 실제 Windows PC(듀얼 모니터, 크롬·엣지·한글)에서 확인하며 만든 버전이에요. 남은 확인 항목은 아래 "확인 항목"에 적어 뒀어요.

## 쓰는 법

| 단축키 (기본값) | 하는 일 |
|---|---|
| `Ctrl+Alt+A` | 선택 화면 열기 |
| `Ctrl+Alt+W` | 선택 없이 지금 쓰던 창 바로 찍기 |

키를 잊어도 괜찮아요. 작업 표시줄 오른쪽 **알림 영역의 파란 아이콘**에 마우스를 올리면 단축키가 보이고, 아이콘을 클릭하면 선택 화면이 열려요. 오른쪽 클릭하면 "지금 쓰던 창 찍기", "캡처 폴더 열기" 메뉴가 있어요.

선택 화면에서는:

- **Space** → 지금 쓰던 창 (열리자마자 강조돼 있어요. 외울 키는 `Ctrl+Alt+A` 하나면 돼요)
- **클릭** → 마우스 아래 창 전체 (크롬·엣지 창이 여러 개여도 각각 따로 골라져요)
- **드래그** → 그 영역만 (한글·PDF 등 어느 창이든)
- **Tab** → **창 목록**: 다른 창에 가려졌거나 최소화된 창까지 썸네일로 보여줘요. 가려진 창도 내용 그대로 찍히고, 최소화된 창은 고르면 잠깐 펼쳐서 찍은 뒤 다시 내려요. 알림 영역 아이콘 메뉴의 "창 목록에서 고르기"로 바로 열 수도 있어요
  - 창 목록은 **엣지 → 크롬 → 웨일** 창이 왼쪽 위에 먼저 오고, 그다음 나머지 창이에요
  - 창 목록에서 **크롬·엣지·웨일 창을 누르면 그 창의 탭 목록**이 **미리보기와 함께** 떠요. 미리보기는 선택 화면 뒤에서 탭을 하나씩 넘기며 채우고, 끝나거나 고르면 원래 보던 탭으로 돌려놔요 (창을 앞으로 가져오지는 않아요). 미리보기가 뜬 탭은 그 그림이 그대로 첨부돼요. 탭이 하나뿐이거나 Shift+클릭이면 지금 보이는 탭을 바로 찍어요
- **Shift 누른 채 클릭·드래그·Space** → 여러 장 담기, **Enter**(또는 아래 안내 바 클릭)로 한 번에 첨부
- **Esc** 또는 **오른쪽 클릭** → 취소

캡처하면 Claude 창이 앞으로 나오고 입력칸에 이미지가 붙어요. **자동 전송은 하지 않아요.** 질문을 적고 직접 보내면 돼요.
한 메시지에 최대 20장까지 담을 수 있어요(claude.ai 한도).

## 설치

1. [최신 Release](https://github.com/Sheehanero/snip-to-chat/releases/latest)에서 `snip-to-chat.mcpb`를 받아요. (GitHub 로그인 필요 없어요)
2. Claude 데스크톱 **설정 → 데스크톱 앱 → 확장 프로그램 옆 관리 → 고급 설정 → Extension Developer → Install Extension…** 에서 받은 파일을 골라 설치해요.
   (PC에 따라 `.mcpb`를 더블클릭해도 설치 창이 뜨지만, 연결된 프로그램이 없으면 흰 아이콘으로 보이고 열리지 않아요)
3. 작업 표시줄 오른쪽에 파란 아이콘이 생기면 끝이에요. 단축키나 저장 폴더는 같은 확장 프로그램 화면의 snip-to-chat 설정에서 바꿔요.
4. 새 버전은 같은 방법으로 다시 설치하면 덮어써요.

단축키 표기 예: `Ctrl+Alt+A`, `Ctrl+Shift+1`, `F9`, `Win+Shift+F2`
(글자·숫자 키만 단독으로 쓰거나 `Shift+글자`는 타이핑과 겹쳐서 받지 않아요.)

### 설치 전에 이 PC에서 먼저 점검하기 (선택)

`snip-to-chat-portable.zip`을 받아 풀고 `selftest.bat`을 실행하면 단축키 등록, Claude 창 찾기, 창 캡처, 클립보드, 저장 폴더를 차례로 점검해요.
`run-standalone.bat`은 Claude 연결 없이 단축키만 켜서 선택 화면을 시험해 볼 수 있어요.

## 확인 항목

2026-11-10 실제 PC(Windows 11, 듀얼 모니터, AhnLab V3)에서 확인한 결과예요.

| # | 확인할 것 | 결과 |
|---|---|---|
| 1 | Claude가 켜져 있는 동안 단축키 감시가 살아 있는지 | 확인됨. Claude가 이 프로그램을 2개 띄워도 하나만 단축키·아이콘을 맡고, 맡던 쪽이 꺼지면 다른 쪽이 이어받아요. **Claude를 완전히 껐다 켤 때 같이 꺼지고 켜지는지는 아직 실제 PC에서 확인 전**이에요 (빌드 서버에서는 연결이 끊기면 0.1초 안에 꺼지는 것까지 확인) |
| 2 | Claude 창을 앞으로 가져와 붙여넣는지 | 확인됨. 창·탭 캡처 후 매번 Claude 창을 바로 앞으로 가져와 붙여넣었어요 |
| 3 | 크롬·엣지 창이 검게 안 찍히는지 | 확인됨. 다른 창에 가려진 크롬·엣지·한글 창도 내용 그대로 찍혔어요 (재생 중인 동영상 영역만 검게 나올 수 있어요) |
| 4 | 백신이 막지 않는지 | 확인됨. V3에서 설치·실행이 막히지 않았어요. 휴대용 zip을 풀어 쓰면 실행할 때마다 Windows의 '게시자 확인 불가' 경고가 떠요 |

작동 상태는 Claude에게 "snip-to-chat 작동 상태 보여줘"라고 하면 볼 수 있어요.

## 캡처 저장과 섞임 방지

캡처는 `%LOCALAPPDATA%\snip-to-chat\captures`에 저장되고 최근 200장만 남겨요. 캡처가 공개 저장소에 섞이지 않도록 세 겹으로 막아요.

1. 기본 저장 위치가 저장소와 상관없는 앱 데이터 폴더예요.
2. 저장 폴더나 그 상위 폴더가 git 저장소면 프로그램이 **저장을 거부**해요 (설정에서 잘못 바꿔도 막혀요).
3. 이 저장소의 `.gitignore`가 이미지 파일을 전부 막고 `assets/`만 허용해요. 빌드 자동화도 `assets/` 밖 이미지가 커밋되면 실패해요.

로그: `%LOCALAPPDATA%\snip-to-chat\snip-to-chat.log`

## 알려진 한계

- 붙여넣을 때 클립보드를 쓰기 때문에, 캡처 뒤에는 클립보드 내용이 마지막 캡처 이미지로 바뀌어 있어요.
- 이 프로그램이 켜져 있는 동안 같은 단축키를 쓰는 다른 프로그램(예: 한글의 단축키)은 그 조합이 안 먹어요. 겹치면 설정에서 바꾸세요.
- 코드 서명이 없는 실행 파일이라, 받은 zip을 풀어 쓰는 휴대용 버전은 실행할 때마다 "게시자를 확인할 수 없습니다" 보안 경고가 떠요.
- 탭 미리보기는 탭마다 0.5초 안팎 걸려서, 탭이 많으면 다 채워지는 데 시간이 걸려요(그동안에도 고를 수 있어요). 탭을 넘기는 동안 그 페이지들은 잠깐 '보이는 상태'가 되므로, 영상·강의 페이지가 화면에 보일 때만 재생되는 식이면 잠깐 반응할 수 있어요. 메모리 절약으로 잠든 탭은 다시 불러오느라 덜 그려진 채 찍힐 수 있어요
- 재생 중인 동영상 영역은 창 캡처에서 검게 나올 수 있어요 (그 부분만 필요하면 드래그 영역 캡처를 쓰세요).
- 창을 직접 그리는 방식이 빈 화면을 돌려주는 창은 화면에 보이는 그대로 잘라내요(이때는 가려진 부분이 같이 찍혀요).
- 시험 모드(`run-standalone.bat`)와 Claude에 설치한 것을 동시에 켜면 단축키는 먼저 켠 쪽만 잡아요. 시험 모드는 이미 켜져 있으면 알리고 꺼져요.
- 영역 캡처는 선택 화면을 연 순간의 화면을 잘라내요. 창 클릭은 그 창을 직접 그려서 찍지만, 그게 실패하면(빈 화면) 화면에 보이는 그대로 잘라내요.

## 개발

```
src/snip_to_chat/
  config.py       단축키 파싱·설정
  geometry.py     좌표·창 판정
  imaging.py      빈 화면 판정, PNG/DIB 변환
  storage.py      저장 + git 저장소 가드
  mcp_server.py   MCP(stdio) 서버
  win32.py        Windows API (창 목록, PrintWindow, 클립보드, 활성화, 단축키)
  overlay.py      선택 화면 (tkinter)
  app.py          조립 + MCP 도구
  selftest.py     자체 점검
```

```
pip install -r requirements-dev.txt
python -m pytest -q
```

`v*` 태그를 올리면 GitHub Actions가 Windows에서 빌드·시험한 뒤 Release에 `.mcpb`와 휴대용 zip을 올려요.
